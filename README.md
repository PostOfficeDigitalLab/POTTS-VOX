# POTTS-VOX

POTTS-VOX is a PODLAB tool for temporary dialogue generation and reference-based performance voice conversion.

## Download

[Download for Mac — Apple Silicon](https://github.com/PostOfficeDigitalLab/POTTS-VOX/releases/latest/download/POTTS-VOX-macOS-arm64.zip)

Extract the ZIP and move POTTS-VOX.app to Applications. Models download on first use. Use voice references with permission and review generated takes. Release notes list the version and compatibility details.

[Release notes and older versions](https://github.com/PostOfficeDigitalLab/POTTS-VOX/releases) · [PODLAB](https://podlab.tv)

This repository contains distribution documentation and release assets. Application source code is not included.
